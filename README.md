# Owaua Brainfuck Bot

A separate, local Discord bot inspired by Owaua. The Discord gateway adapter is Python because Brainfuck has no networking or TLS primitives; the reply templates and response engine are executable Brainfuck programs in `brainfuck/`.

## Run

1. Create a Discord bot application. In the Developer Portal open **Bot**, turn
   on **Message Content Intent** under **Privileged Gateway Intents**, and save.
2. Copy `.env.example` to `.env` and put your token in `DISCORD_TOKEN`.
3. Install dependencies and start it:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python run.py
```

Invite the bot with View Channels, Send Messages, and Read Message History.

Supported behavior:

- Mention the bot for a fully randomized sentence assembled from its local
  English vocabulary. The generated bytes are echoed by a Brainfuck program.
- `!help`
- `!persona rudeish|nerdish|flirty|chaotic`
- `!language english|spanish|french|german|italian|hungarian|romanian|polish|ukrainian|greek|random`
- `!brainfuck`
- `!ping`

The token is intentionally not included in this project. The application ID is
not needed by the runtime; Discord identifies the bot from its token.

The English vocabulary is in `brainfuck/vocabulary.txt`; language packs are in
`brainfuck/languages/`. On macOS, the bot uses the system English dictionary
if one is installed.

These are randomized word generators, not translation or semantic language
models. Add another language by placing a whitespace-separated word list in
`brainfuck/languages/<name>.txt` and adding its aliases in `run.py`.
